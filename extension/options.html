前往取得金鑰 ↗

請使用未啟用帳單的免費方案專案金鑰。

擴充功能無法查核帳單；若填入已開通付費的專案金鑰，Google 仍會計費。本擴充功能不會啟用帳單，也不會自動改用付費模型。

「測試翻譯」會用已保存的服務翻譯一句固定英文；保存設定本身不會送出任何文字。

測試譯文

更換金鑰時，直接貼上新的金鑰並保存。

如何選擇

先用 Google 翻譯，
需要時再換 Gemini。

  1. 01
    Google 翻譯不需任何設定，適合日常閱讀。若出現「暫時限制請求」，等幾分鐘再按「重新嘗試」。
  2. 02
    Gemini：在 Google AI Studio 建立金鑰，到專案頁面確認是免費方案、未啟用帳單，不要點「Set up billing」。
  3. 03
    把金鑰貼在左側、勾選確認並保存，再按「測試翻譯」。金鑰只在這個設定頁輸入，請不要貼到聊天或網頁裡。
聊天會員與 API 分開

Gemini、ChatGPT、Claude 等聊天服務的付費會員，不等於 API 金鑰或 API 額度。本擴充功能不會讀取你的登入狀態或 Cookie。

額度與內容

免費不等於無限制，也不保證永久免費。額度用完或被限制時，翻譯會停下並說明原因，不會自動重試或改用付費服務。

兩種服務都會把英文段落送到 Google。請不要用來翻譯機密內容。

◇

API Key 只保存在這個 Chrome 設定檔的本機擴充功能儲存區（不是加密保管庫），不會同步、不會寫入安裝包，也不會交給網頁內容程式；只由背景程式放在送往 Google Gemini 的請求標頭中。翻譯時傳送英文段落；使用 Gemini 時另附網頁標題、章節標題與前後段落摘錄。不傳送網址或 Cookie。
