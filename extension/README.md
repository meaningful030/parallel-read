# 雙語讀 · Parallel Read 0.3.1

Chrome 雙語網頁翻譯擴充功能：英文原文留在上方，每段下方顯示台灣繁體中文，可一鍵還原。

## 安裝或更新

1. 在 Chrome 開啟 `chrome://extensions`，開啟右上角「開發人員模式」。
2. 若已裝舊版（0.1.1 或 0.2.0），先在卡片上看版本號，再按「移除」，避免兩份同時存在。
   - 從 0.3.0 更新：把新檔案**覆蓋到原本載入的資料夾**，再按卡片上的重新載入（↻）即可，服務設定與金鑰會保留。改載入別的資料夾會被當成另一個擴充功能，設定要重填。
3. 按「載入未封裝項目」，選擇**直接包含 `manifest.json` 的資料夾**（ZIP 請先解壓縮）。
4. 重新整理想翻譯的網頁，把「雙語讀」固定在工具列。

不需要 Node.js 或其他套件。載入後請保留這個資料夾。

## 翻譯服務

兩種服務都不必付費就能開始用，但**免費不等於無限制，也不保證永久免費**。在設定頁（面板的「翻譯服務設定」）切換。

| | Google 翻譯（預設） | Gemini（選用） |
| --- | --- | --- |
| 需要什麼 | 什麼都不用 | Google 帳號，在 [AI Studio](https://aistudio.google.com/api-keys) 建立 API 金鑰 |
| 模型 | Google 翻譯網頁工具使用的公開介面 | `gemini-3.8-flash`（預設）或 `gemini-3.5-flash-lite` |
| 額度 | 沒有公開額度；短時間翻太多段會被暫時限制 | 依專案而定，只能在 AI Studio 查看；每日於美國太平洋時間午夜重置 |
| 帳單 | 無 | 不需要。請確認專案沒有啟用帳單；擴充功能無法替你查核 |
| 前後文 | 逐段翻譯，不參考前後文 | 參考網頁標題、章節標題與前後段，每次批次翻譯數段 |
| 文字送到 | Google | Google；免費方案的內容可能被 Google 用於改善產品 |

- Google 翻譯介面位址是 `translate.googleapis.com/translate_a/t`，**不是有服務保證的正式 API**，Google 可能隨時變更或限制。
- Gemini 兩個模型都是官方價格表列有免費方案的模型（2026-11-08 核對）。擴充功能只允許這兩個模型，不會改用付費模型或開啟帳單。
- 聊天服務的付費會員不是 API 金鑰，本擴充功能也不會讀取任何登入狀態或 Cookie。

## 使用

1. 開啟英文網頁，點「雙語讀」→「翻譯這個網頁」。畫面附近的段落會先翻，往下捲動會繼續。
2. 「還原網頁」移除所有譯文；重新整理網頁也會還原。
3. 服務被限制、額度用完或出錯時，翻譯會**停下並說明原因**，不會自動重試。等一下再按「重新嘗試」。
4. 更換服務或金鑰後，已開啟的網頁按「重新嘗試」會清掉舊譯文，以新設定重新翻譯，不會混用。

面板的「試讀範例」會開啟內附的英文文章。

## 資料與金鑰

- 翻譯時傳送英文段落。使用 Gemini 時另附網頁標題（最多 160 字元）、章節標題，以及前一段（最多 600 字元，含已完成的譯文）與下一段（最多 400 字元）。不傳送網址或 Cookie。
- 程式碼（`code`、`kbd` 等）和標示為不翻譯的文字會換成 `[[0]]` 佔位符，譯完再放回原文。
- 數學公式（MathJax、KaTeX、MathML、Wikipedia）：數字（如 90、1.5、50%）與單一字母變數（如 n）直接放進句子一起翻譯；較長的公式換成佔位符，譯文中以一行文字顯示（如 `x²`、`SE = σ/√n`）。
- Gemini 金鑰只能在設定頁輸入，保存在這個 Chrome 設定檔的 `chrome.storage.local`（不是加密保管庫），不同步、不在安裝包內，網頁內容程式無法讀取；只由背景程式放在送往 Gemini 的 `x-goog-api-key` 標頭。
- 「清除金鑰」會刪除本機金鑰並取消排隊中的請求；已送出的請求無法收回。要撤銷金鑰本身，請到 AI Studio 刪除。
- 沒有分析追蹤；譯文只暫存在背景程式記憶體。

## 限制

- 支援一般 HTML 網頁。PDF、圖片文字、Canvas、影片字幕、內嵌框架與 Shadow DOM 不支援；Chrome 內建頁面與線上應用程式商店無法翻譯。
- 導覽列、輸入框、程式碼區塊會略過；只有一個單字的選單或標籤（標題除外）不翻譯。
- 譯文中的公式是純文字（如 `∑_(i = 1)^n`），不是排版後的公式，複雜公式請看上方原文。以圖片呈現、且沒有 MathML 或 TeX 原始碼的公式讀不到。
- 機器翻譯仍會出錯。實測 Google 翻譯會漏掉「as much as（最多）」這類程度用語，也會出現少數中國用語；原文保留在上方方便核對。
- Gemini 模式依官方文件實作，**尚未用真實金鑰測試**。
- 尚未在桌面 Chrome 載入後做整合測試；詳見專案根目錄的 `改善報告.md`。
